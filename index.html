Myron Career Agent

A personal application operated by Jamin Cleveland to organize career research and identify relevant job opportunities.

The application runs on its owner's server. It combines public job-source research with a separately authorized Gmail connection for identifying career-related correspondence. It is for the owner's use and does not offer public registration or access to anyone else's mailbox.

Read-only Gmail connection

The current Gmail utility confirms the authorized account and reads a bounded sample of message metadata matching a career-related search. It stores message and thread identifiers, timestamps, and selected headers such as sender, recipient, subject, date, and Message-ID.

It requests the Google permission https://www.googleapis.com/auth/gmail.readonly. This permission allows reading Gmail data; the current implementation uses metadata and does not retrieve message bodies or attachments. It does not send messages, delete or archive mail, or change labels.

Authorization and control

The owner grants access using Google's OAuth consent flow. The application stores access and refresh credentials in a private directory on the owner's server. Access can be revoked through the owner's Google Account settings.

Privacy

The current Gmail utility does not send retrieved email data to external AI services. Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models. Details about storage, retention, access revocation, and deletion are in the privacy policy.
