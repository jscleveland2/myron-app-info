Privacy policy

Myron Career Agent
Effective date: October 5, 2026

Myron Career Agent is a personal career research application operated by Jamin Cleveland. This policy describes the current Gmail connection and this public information website. The application is for its owner's use and does not provide public account registration.

Google account access

The application uses Google OAuth to obtain the owner's explicit consent for https://www.googleapis.com/auth/gmail.readonly. This permission permits read access to Gmail. The current utility confirms the connected email address and reads a bounded sample of career-related message metadata.

The owner enters account credentials only through Google's authorization flow. The application does not collect or store the owner's Google password. It stores OAuth access and refresh tokens so it can access the authorized mailbox and refresh authorization without requesting the password.

Information accessed and stored

The current Gmail utility processes the connected email address, message and thread identifiers, internal message timestamps, and selected headers: From, To, Subject, Date, and Message-ID. Its saved sample also includes the search query and retrieval time. These headers may contain information about email correspondents.

The current utility does not retrieve message bodies, attachments, or snippets. It does not send, delete, or archive email, or modify mailbox labels. The read-only permission covers the mailbox; the application's search query limits the sample it actually retrieves.

Purpose and use

Gmail information is used to confirm the connection and identify career-related correspondence for the owner's job search. Retrieved metadata is treated as untrusted evidence and does not authorize external communications or change decision policies.

Google user data is not sold, used for advertising, used for surveillance, or used to train generalized AI or machine-learning models. The current Gmail utility does not transfer retrieved email data to external AI services or publish it on this website.

Storage and access controls

OAuth credentials and retrieved metadata are stored on the owner's server in directories with restricted operating-system permissions. They are kept outside the application source repository and are not included in the public website repository. Connections to Google's API use HTTPS.

The application's infrastructure providers process data as needed to host and operate the owner's server. Application data is intended for the owner and any operator he explicitly authorizes for maintenance. The utility's public status output excludes credentials and email headers.

Retention and deletion

The current utility replaces its bounded metadata sample on each successful ingestion run; it does not maintain an append-only archive of retrieved messages. Saved credentials remain until the owner removes them. There is no automatic time-based deletion in this version.

The owner can stop the application, revoke its Google access, and delete saved OAuth credentials and metadata from the server. Any separately created copies or infrastructure backups must also be deleted to remove retained copies. Revoking authorization prevents future access but does not itself erase previously saved data.

Revoke access

The owner can revoke Myron Career Agent's access through Google Account third-party connections. Further use then requires new authorization.

Public website

This website contains application information and this policy. It has no sign-in form, Gmail connection endpoint, analytics scripts, advertising, or tracking cookies added by the application operator. It is hosted on GitHub Pages. GitHub logs visitor IP addresses for security purposes, as described in GitHub's Pages documentation and GitHub's privacy statement.

Google API policy

Myron Career Agent's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

This policy will be updated before the application expands the types of Gmail data it processes or introduces new uses or disclosures. Any new permissions or data uses requiring consent will be presented to the owner before being enabled.

Contact

For privacy questions or deletion assistance, contact Jamin Cleveland at jscleveland@gmail.com.
